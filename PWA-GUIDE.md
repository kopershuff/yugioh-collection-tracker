# Guide d'installation - Application Mobile Yu-Gi-Oh Checklist

Votre application Yu-Gi-Oh Checklist est maintenant une **Progressive Web App (PWA)** qui peut être installée comme une application mobile native sur Android et iOS !

## 📱 Installation sur Android

### Via Chrome ou Edge
1. Ouvrez l'application dans votre navigateur Chrome ou Edge
2. Cliquez sur le bouton **"Installer l'app"** qui apparaît en haut à droite
   - OU appuyez sur le menu (⋮) et sélectionnez "Installer l'application"
3. Confirmez l'installation
4. L'icône de l'application apparaîtra sur votre écran d'accueil

### Via Firefox
1. Ouvrez l'application dans Firefox
2. Appuyez sur le menu (⋮)
3. Sélectionnez "Installer"
4. Confirmez l'installation

## 🍎 Installation sur iOS (iPhone/iPad)

### Via Safari (recommandé)
1. Ouvrez l'application dans Safari
2. Appuyez sur le bouton de partage (carré avec une flèche vers le haut)
3. Faites défiler et sélectionnez **"Sur l'écran d'accueil"**
4. Nommez l'application (ex: "Yu-Gi-Oh Checklist")
5. Appuyez sur "Ajouter"
6. L'icône apparaîtra sur votre écran d'accueil

**Note**: Sur iOS, la PWA doit être installée via Safari. Chrome et Firefox ne supportent pas encore cette fonctionnalité sur iOS.

## ✨ Avantages de l'installation

Une fois installée, l'application :
- ✅ S'ouvre comme une application native (plein écran)
- ✅ Apparaît dans votre liste d'applications
- ✅ Fonctionne hors ligne (données en cache)
- ✅ Se lance plus rapidement
- ✅ Offre une meilleure expérience utilisateur
- ✅ Économise de la batterie

## 💾 Données sauvegardées

Toutes vos données sont stockées localement sur votre appareil :
- Cartes possédées
- Quantités de cartes
- Raretés sélectionnées
- Liste de souhaits
- Filtres et préférences

**Important**: Les données restent sur votre appareil même après installation. Elles ne sont pas synchronisées entre appareils.

## 🔄 Mises à jour

L'application se mettra à jour automatiquement lorsque vous la rouvrez après une mise à jour du site web.

## 🗑️ Désinstallation

### Android
1. Maintenez l'icône de l'application enfoncée
2. Sélectionnez "Désinstaller" ou "Supprimer"

### iOS
1. Maintenez l'icône de l'application enfoncée
2. Sélectionnez "Supprimer l'app"
3. Confirmez la suppression

## 🆘 Problèmes courants

**L'application ne s'installe pas ?**
- Assurez-vous d'utiliser un navigateur compatible (Chrome, Edge, Safari)
- Vérifiez que vous avez une connexion internet
- Sur iOS, utilisez exclusivement Safari

**Mes données ont disparu ?**
- Les données sont stockées dans le cache du navigateur
- Si vous videz le cache, les données seront perdues
- Ne désinstallez pas l'application si vous voulez garder vos données

**L'application ne fonctionne pas hors ligne ?**
- Assurez-vous d'avoir chargé l'application au moins une fois en ligne
- Certaines fonctionnalités (prix des cartes, actualisation) nécessitent une connexion
